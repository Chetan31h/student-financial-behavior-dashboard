# 📊 Financial Awareness Dashboard

This project analyzes financial awareness among college students using survey data and Power BI.

## 🔍 Overview
- Data collected using Google Forms
- Cleaned using Python (Pandas)
- Visualized using Power BI

## 📈 Key Insights
- Majority of students have low income and low savings
- Limited awareness of investment tools (Demat accounts)
- High financial dependency among students

## 🛠️ Tools Used
- Python (Pandas)
- Power BI
- DAX

## 📂 Project Structure
- data/ → Raw and cleaned datasets
- notebook/ → Data cleaning process
- dashboard/ → Power BI file
- images/ → Dashboard preview
